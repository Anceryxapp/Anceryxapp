## 🇧🇷 Sobre a Anceryx

A **Anceryx** é uma plataforma social em desenvolvimento para aproximar pessoas, descobrir comunidades e compartilhar momentos — com diferentes formas de interação em um só lugar.

### ✨ O que estamos construindo

| | Experiência |
|:--:|---|
| 📰 | **Feed** — compartilhe publicações e momentos. |
| 🧭 | **Explore** — descubra pessoas e novos conteúdos. |
| 💬 | **Chat** — converse com sua galera. |
| 📞 | **Chamadas** — conecte-se em tempo real. |
| 🔴 | **Ao vivo** — acompanhe e participe de transmissões. |
| 🗣️ | **Fóruns** — crie tópicos e participe de discussões. |
| 🎨 | **Personalização** — expresse sua identidade dentro da comunidade. |
